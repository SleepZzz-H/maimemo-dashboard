绑定你的墨墨账号

填一个墨墨开放 API 的 Token，就能把你墨墨里正在背的词拿来自测，题目按你自己的复习次数和遗忘情况挑。

Token 只存在你自己的浏览器里（登录后也会存进你的云端账号）；本站不保存你的墨墨密码，也拿不到。没有 Token 的话去 open.maimemo.com 免费申请一个。

登录，进度存云端

登录后换手机、换电脑都接着做；朋友注册自己的账号，各存各的进度。

只用邮箱+密码，不收集别的。密码由 Supabase 保存，本站只存登录凭证。

账号

没登录：答题进度只存在这台设备上，换手机、换电脑都看不到。用邮箱注册一个账号（不绑定手机号），进度就存到云上，走到哪接着做。
